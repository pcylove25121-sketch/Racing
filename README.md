# 벼랑길 GP

네온펑크 3D 모바일 레이싱 게임이에요. 브라우저에서 바로 실행되고, 로그인 없이 친구와 멀티플레이할 수 있어요.

- **혼자 하기**: AI 5대와 3랩 레이스. 코스 4개(네온 메가시티, 선셋 캐니언, 레인 다운타운, 스카이 스파이럴).
- **멀티플레이**: `멀티플레이 → 방 만들기`를 누르면 코드 4자리와 초대 링크가 생겨요. 친구가 초대 링크(`…/#코드`)를 열면 같은 방에 들어와요. 최대 6명이 사람끼리만 달려요(AI 없음).

멀티플레이는 플레이어끼리 직접 연결(WebRTC)하고, 처음 서로를 찾을 때만 무료 공개 PeerJS 서버를 써요. 일부 회사·학교 와이파이나 모바일 데이터 망에서는 직접 연결이 막힐 수 있어요. 방장이 나가면 방이 끝나요.

조작: 왼쪽 패드 핸들 · 브레이크+핸들 드리프트 · NITRO 부스트 · ↺ 트랙 복귀. 키보드는 방향키/WASD, Space 니트로, Shift 드리프트, R 복귀.
